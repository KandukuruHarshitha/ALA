# Assignment 1 - Vector Abstraction and Statistical Operations

## Overview
This folder implements a custom `Vec` class for educational use in Applied Linear Algebra. It provides basic vector storage using Python tuples and implements fundamental statistical operations:
- `mean()`: Computes the arithmetic average of vector components.
- `demean()`: Centers the vector by subtracting its mean from every element.
- `std()`: Computes the population standard deviation.
